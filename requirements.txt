# Installing this pulls in PyTorch. For a CPU-only install, which is several

#
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt

# NOTE on what is deliberately absent:
#
# - pandas. The archive is a few thousand rows read once into a list of
#   frozen dataclasses; numpy covers the matrix work in core/features.py and
#   nothing here needs a DataFrame.
# - scipy. core/stats_tests.py implements the four distribution functions the
#   analysis needs, in about a hundred lines. Every number in the validation
#   report is a claim about whether a prediction beat chance, and a reader has
#   to be able to check how the p-value was produced without leaving the repo.
# - beautifulsoup4. core/sources/html_table.py deliberately does not key on
#   CSS classes or the DOM; it works on rows, cells and positions, which the
#   standard library handles.
